# 功能总览

- **核心 root**：内核级 `su` 与权限管理、metamodule 系统less 模块（含批量操作、`banner=` 封面、备份恢复）、按应用 App Profile（含限时授权）。
- **Origin Veil**：内核级探测感知与按应用隐藏（英文详情：[Origin Veil](/features/veil)）。
- **OriginZygisk**：管理器内置 Zygisk 引擎（[详情](/features/zygisk)）。
- **OriginTune**：首页卡片直达内核调参（[详情](/features/tune)）。
- **OriginGuard 与 SuSFS**：模块安装前审计 + 一键强隐藏（[详情](/features/guard)）。
- **KPM 与刷写**：KPM 标签页、直接安装、AnyKernel3、离线修补（[详情](/features/kpm-flasher)）。
- **管理器**：Material / MIUIX 风格、动态图标、悬浮栏等（[详情](/features/manager)）。
